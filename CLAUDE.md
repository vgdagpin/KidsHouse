# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A plan for a 120 × 120 cm wooden kids playhouse. There is no application code, build system, or test suite. The folder holds a reference drawing, an annotated copy of it, and a standalone HTML build guide. It is not a git repository.

## Design numbers (single source of truth)

The drawing gives width, depth and height as 120 cm each. Everything else was derived from it and must stay consistent across the image overlay and the HTML tables:

| Item | Value |
|---|---|
| Enclosed room | 120 W × 80 D cm |
| Porch | 120 W × 40 D cm |
| Porch front split | 35 cm left railing / 50 cm opening / 35 cm right railing |
| Porch sides | railing on both sides, 50 cm high, rails about 33 cm, three balusters per side |
| Wall (eave) height | 90 cm; ridge 120 cm; roof pitch 1:2 (~27°), 10 cm overhang |
| Serving window | 45 × 35 cm, sill 55 cm, top 90 cm, left side wall |
| Door | 40 × 75 cm, rough opening 45 × 80 cm |
| Framing | 2×2 = 38 × 38 mm walls and rafters; 2×4 = 38 × 89 mm floor, ridge and beams |

Derived framing used in the diagrams and the cut list: studs 82.4 cm; left wall has window studs 45 cm apart, a 45 cm sill between them and two 47.4 cm cripples; front wall door jacks 76.2 cm under a 52.6 cm header plus 2.4 cm packers; porch posts notched 3.8 × 8.9 cm for the front beam, side beams about 33 cm; rafters cut from 78 cm stock with a 3.8 cm seat / 1.9 cm heel birdsmouth; railing rails about 24 cm, balusters 37.4 cm with about 5.5 cm gaps.

If any of these change, update `build-guide.html` (dimensions table, cut list, step text, diagrams) and the overlay.
